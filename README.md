# Приложение для анализа банковских операций
## Приложение для анализа транзакций, которые находятся в Excel-файле.Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставляет другие сервисы.
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/NataliPochekutova/my_first_project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Основные модули, реализованные в проекте:
- Модуль views.py. В нем реализован набор функций, формирующих 
информацию по каждой карте, топ-5 транзакций по сумме платежа, курс валют, стоимость акций из S&P500.
- Модуль main.py - принимает на вход строку с датой и временем 
 и возвращающую JSON-ответ с данными из модуля views.py
- Модуль services.py. В нем реализованы функции анализирующие, 
какие категории были наиболее выгодными для выбора в качестве категорий повышенного кешбэка
- Модуль reports.py. В нем реализованы функции форирующие отчет о тратах по категориям.
